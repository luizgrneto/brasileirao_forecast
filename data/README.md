# Dados

Nada deste diretório é versionado, exceto este arquivo (veja `.gitignore`).

- `raw/`: dados brutos, exatamente como foram coletados. Criado pelos scripts de coleta.
- `processed/`: dados tratados (Parquet), prontos para análise e modelagem.

De onde cada fonte vem, sob quais termos e quando foi coletada: [`docs/sources.md`](../docs/sources.md).
